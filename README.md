# My very own retro and pop art themed portfolio

Working on your portfolio for the first time is really exciting, my goal with this portfolio was to show more
of my personality along with my work and I wanted to implement cool creative interactions with simple tech stack. I'm intentionally not using a lot of languages for the website, while keeping the creative aspects I also wanted 
to make sure the website isn't very bloated, so that the user can have seemless experience. 

**NOTE**: if you do modify my portfolio or use any assets, you must contact me about how you're going to use them and provide proper credits.



File Structure:




## Z-index

- black cards in ```black-card.css```= 1
- header in ```style.css``` = 999
- noise filter in ```style.css``` = 1000
- torn paper img in ```work-philosophy.css``` = 1
- closing text in ```work-philosophy.css``` = 2
